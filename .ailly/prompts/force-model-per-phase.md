# Per Phase Model Checking

Before starting a phase, check what the current model is. Choose the right size model for each phase. For Anthropic, that's Claude Haiku (thinking) for research, Opus (max effort) for design, Sonnet (high effort) for planning, and Sonnet[1m] (high effort) for implementation. If you can change the model yourself, great. If not, inform the user to use the /model command if they want and then continue the chat. If they didn't change the model, keep what they're on.
