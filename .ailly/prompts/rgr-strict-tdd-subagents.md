# Strict Subagent TDD

red-green-refactor is, today, a bit wishy-washy when practiced by bug fix where it fixed the feature then changed the test. Maybe this is ok?

But the big idea is to switch from one conversation doing the entire plan to doing subagent per plan step, and then subagent-to-test, sugagent-to-implement, subagent-to-refactor, basically constraining each text in what its allowed to do.
